# Changelog

## [1.0.1] - 2026-10-07

### Added

- Status permission notifikasi macOS di dalam aplikasi.
- Tombol **Tes notifikasi** untuk menguji notifikasi tanpa menunggu waktu sholat.
- Banner reminder di dalam window aplikasi.
- Fallback membuka window ketika native notification gagal.

### Fixed

- Memperbaiki notifikasi macOS yang tidak muncul karena permission belum diminta.
- Scheduler sekarang melakukan pengecekan awal setelah aplikasi siap.
- Metadata aplikasi disamakan dengan nama Prayer Reminder dan bundle identifier resmi.

### Changed

- Versi aplikasi dinaikkan dari 1.0.0 ke 1.0.1.
